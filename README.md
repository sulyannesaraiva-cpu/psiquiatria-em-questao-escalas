# MENTIUM — codinome provisório
Ferramentas gratuitas para a prática psiquiátrica.

- Sem limite mensal de aplicações.
- Sem cadastro.
- Curadoria em vez de quantidade.
- Aplicação orientada, pontuação e interpretação.
- Sem armazenamento de dados clínicos nesta versão.

Projeto estático preparado para GitHub + Vercel.


## v68 — PsiqMetria
Interface híbrida com barra lateral responsiva, navegação por contexto clínico, catálogo preservado e sem dependências externas.


## v69 — Fluxo clínico
- Seletor de sintomas com sugestões explicadas de instrumentos existentes no catálogo.
- Biblioteca recolhida por padrão, com busca e filtros originais preservados.
- Sugestões são heurísticas de navegação, não diagnóstico ou recomendação de conduta.
- Não armazena seleção de sintomas.
